# Quality Metrics Rerun README

Created: 2026-06-10

Use this script as the canonical evaluator for Try80 quality metrics:

`C:\TFG\TFGAllProgress_Tries_and_Attempts\TFGEightiethTry80\scripts\compare_prior_try80_all_quality_metrics.py`

It calculates all four metrics in one pass:

- RMSE
- masked SSIM
- MapCorr
- GradCorr

It also calculates all three comparison pairs:

- `prior`: GT-prior
- `model`: GT-model
- `prior_vs_model`: prior-model

## Why This Script Exists

The older SSIM and structure-metric runs were generated by separate scripts.
Those old runs had masking/aggregation issues:

- SSIM local windows could include invalid/no-data pixels.
- MapCorr aggregation did not match the per-map z-score wording.
- GradCorr gradients could cross invalid/no-data boundaries.

The combined script avoids split definitions by computing RMSE, SSIM, MapCorr,
and GradCorr from the same arrays, masks, model outputs, and pair definitions.
LoS/NLoS scopes are used as reporting subsets for center pixels; they are not
treated as local-neighborhood boundaries for SSIM or GradCorr.
